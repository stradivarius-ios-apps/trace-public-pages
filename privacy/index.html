TrAce · Оновлено 11 жовтня 2026 року

TrAce зберігає ваш журнал локально на iPhone та не надсилає його розробнику.

Дані в застосунку

Назви звичок, поля, варіанти відповідей, дати подій, відповіді, ручна тривалість, умови, налаштування діаграм і цілей зберігаються в локальному сховищі застосунку. Вони потрібні для вашого журналу та аналітики. Розробник не отримує ці записи, не продає їх і не передає третім сторонам.

Акаунти та синхронізація

TrAce не має акаунтів, сервера, CloudKit або власної хмарної синхронізації. Застосунок не синхронізує записи між пристроями. Системна резервна копія iPhone, зокрема iCloud Backup, може включати дані застосунку залежно від ваших налаштувань Apple. Це окремий механізм операційної системи. TrAce не керує такими копіями й не має власного експорту або відновлення з файлу.

Реклама, аналітика та дозволи

TrAce не використовує рекламу, сторонні аналітичні або crash-reporting SDK чи відстеження користувачів. Застосунок не запитує доступ до геолокації, контактів, фото, камери або мікрофона.

Зберігання та видалення

Записи залишаються локально, доки ви їх не видалите. Подію можна видалити в журналі; архівування звички, поля або варіанта зберігає історію. Видалення застосунку з iPhone видаляє його локальні дані. Раніше створені системні резервні копії регулюються налаштуваннями Apple. Розробник не може відновити ваш журнал.

Зовнішні сторінки й підтримка

Посилання підтримки та конфіденційності відкривають зовнішній вебсайт. Ці сторінки розміщені на GitHub Pages, без доданих нами cookies, аналітики, форм чи сторонніх скриптів. GitHub може обробляти технічні дані відвідування відповідно до своєї політики.

Якщо ви добровільно звертаєтеся через GitHub Issues, зміст звернення та ваш GitHub профіль стають публічними. Не публікуйте особистий журнал або іншу конфіденційну інформацію. Це окреме звернення на зовнішній платформі, а не автоматичний збір даних застосунком.

Зміни політики

Якщо майбутня версія змінить обробку даних, цю політику та декларації App Store буде оновлено перед випуском.

Контакт

З питаннями щодо приватності звертайтеся до розробника через сторінку підтримки TrAce. Звернення є публічними.
